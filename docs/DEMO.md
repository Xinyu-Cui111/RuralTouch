1. 微信开发者工具打开 **`E:\RuralTouch-mp`**（或 `dist/build/mp-weixin`）

## 脚本（约 5–6 分钟）

### 开场（30s）

> 「指尖善治做基层调解垂直 AI：说事 → AI 整理成案 → 建档 → 干部推进。不是泛 Chat。」

### 1. 登录合规（20s）

协议勾选 → 微信登录。

### 2. AI 整理成案（120s）⭐

1. 议事厅 → 提交纠纷 → Chip「土地边界」→ 补口述 → **整理成案**
2. 指给面试官：**风险、参考依据、建议步骤、来源标签、免责**
3. （可选）同文案再点一次整理 → 来源变 **短缓存**（省成本叙事）
4. （可选）改文案含「打架/受伤」→ **红色升级条 + 110/120**
5. 确认提交 → 建档 → 「咨询此案」顶栏本案 chip

### 3. 干部推进（45s）

调解员工作台：看 **待受理/办理中/升级优先** → 一键受理 → 办理 → 办结。

### 4. 质量闭环（30s，加分）

AI 质量看板：调用量 / 升级率 / 来源分布；或对错案点「标 Badcase」。

### 5. 收尾（20s）

> 「评测集盯分类与高风险召回；无 LLM Key 也能规则降级。辅线交互可提 AegisFlow。」
