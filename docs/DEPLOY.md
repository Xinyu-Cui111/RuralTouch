# 微信小程序发布指南

本文档帮助你将「指尖善治」发布到微信开发者平台并通过审核。

## 一、后端方案：微信云开发

已选用 **微信云开发**，原因：

- 与小程序原生集成，无需自建服务器和备案域名
- 内置用户身份（OpenID）、数据库、云函数
- 审核合规路径清晰，适合个人/小团队真实上线
- H5 模式自动回退 Mock 数据，方便面试演示

## 二、首次配置（必做）

### 1. 开通云开发

1. 用微信开发者工具打开编译产物目录：
   - 开发：`unpackage/dist/dev/mp-weixin`
   - 发布：`dist/build/mp-weixin`
2. 顶部菜单 → **云开发** → **开通**
3. 创建环境（建议命名 `ruraltouch-prod`）
4. 复制 **环境 ID**

### 2. 填写环境 ID

编辑 `config/env.js`：

```js
export const CLOUD_ENV_ID = "你的环境ID";
```

### 3. 部署云函数

1. 在微信开发者工具左侧找到 `cloudfunctions/rt-api`
2. 右键 → **上传并部署：云端安装依赖**
3. 等待部署完成

### 4. 创建数据库集合

在云开发控制台 → 数据库，新建以下集合：

| 集合名             | 说明       |
| ------------------ | ---------- |
| `rt_users`         | 用户信息   |
| `rt_notices`       | 村务通知   |
| `rt_disputes`      | 纠纷调解   |
| `rt_feedbacks`     | 村民反馈   |
| `rt_moral_records` | 积分记录   |
| `rt_mall_items`    | 积分商城   |
| `rt_products`      | 团购商品   |
| `rt_meta`          | 初始化标记 |

**权限建议（开发期）：**

- 所有用户可读：`rt_notices`, `rt_mall_items`, `rt_products`
- 仅创建者可读写：`rt_users`, `rt_disputes`, `rt_feedbacks`, `rt_moral_records`

生产环境建议全部改为「仅云函数可写」，客户端只通过 `rt-api` 云函数访问。

### 5. 初始化种子数据

首次用户登录时云函数会自动写入基础数据。也可在云开发控制台手动调用云函数：

```json
{ "action": "initSeed", "data": {} }
```

## 三、本地开发

```bash
npm install
npm run dev:mp-weixin   # 微信小程序
npm run dev:h5          # H5 演示（Mock 数据）
```

## 四、提审前检查清单

### 功能

- [ ] 微信一键登录可用
- [ ] 纠纷提交 → AI 分析 → 证据上传 → 详情时间线
- [ ] AI 村务助手、AI 普法顾问可用
- [ ] 村务通知、村民反馈可提交
- [ ] 积分申报（审核制）、积分商城兑换可用
- [ ] 管理后台可改纠纷状态（管理员）
- [ ] 用户协议、隐私政策页面可打开

### AI 与大模型

- [ ] 云函数 `rt-api` 已重新部署（含 aiAssistDispute / aiLegalChat）
- [ ] （可选）配置 `LLM_API_KEY`，见 [LLM_SETUP.md](./LLM_SETUP.md)
- [ ] 云存储已开通（证据照片上传）

### 管理员

- [ ] 环境变量 `ADMIN_OPENIDS` 已配置，或 `rt_users.isAdmin = true`

### 合规（微信审核必查）

- [ ] 小程序后台 → **设置 → 基本设置 → 服务内容声明** 填写完整
- [ ] 小程序后台 → **设置 → 用户隐私保护指引** 配置并同步到代码
- [ ] `manifest.json` 已开启 `__usePrivacyCheck__`
- [ ] 登录页有协议勾选，链接到 `pages/agreement/user` 和 `pages/agreement/privacy`
- [ ] 不涉及未声明的敏感权限（摄像头、定位等）
- [ ] 类目选择：**政务民生 > 政务服务** 或 **生活服务 > 综合生活**

### 素材

- [ ] 小程序名称：指尖善治
- [ ] 简介：智慧村务数字化服务平台
- [ ] 截图：至少 4 张（法治、议事、道德银行、团购）
- [ ] 图标：1024×1024 无圆角原图

## 五、构建发布

```bash
npm run build:mp-weixin
```

在微信开发者工具中：

1. 打开 `dist/build/mp-weixin`
2. 点击 **上传**
3. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 版本管理 → 提交审核

## 六、面试演示建议

**小程序真机演示（最佳）：** 配置云开发后，扫码预览，走完整纠纷调解链路。

**H5 浏览器演示（备用）：** `npm run dev:h5`，无需云环境，自动使用 Mock 数据。

**讲解话术：**

> 后端采用微信云开发，前端 uni-app 一套代码覆盖小程序和 H5。核心链路是纠纷提交、进度追踪、积分联动，已具备用户协议和隐私合规页面，可直接提审上线。

## 七、常见问题

**Q: 云函数调用失败？**  
A: 检查 `config/env.js` 环境 ID、云函数是否已部署、数据库集合是否已创建。

**Q: 登录后无数据？**  
A: 调用 `initSeed` 或重新登录触发自动种子数据写入。

**Q: H5 能连云开发吗？**  
A: H5 默认走 Mock。面试演示推荐小程序真机或开发者工具预览。
