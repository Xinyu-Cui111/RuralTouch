# V4 闭环彻查与修补记录

## 用户痛点：关了老年模式还是 3 个界面、没变化

**根因**：底栏「办事/服务/我的」曾做成全员默认，与「老年简洁模式」脱钩；关模式只动字号，底栏仍是 3 个，体感等于没关。

**已修（绑定关系）**：

| 模式               | 底栏                                           |
| ------------------ | ---------------------------------------------- |
| **标准**（关简洁） | **5 项**：办事 / 法治 / 激励 / 团购 / 我的     |
| **老年简洁**（开） | **3 项**：办事 / 服务 / 我的（其余进服务大厅） |

切换时会 `reLaunch` 当前页，底栏立刻重绘。

### 怎么开关

- **开/关**：我的页顶部「老年简洁模式」
- **关**：办事/服务顶栏「恢复 5 项底栏」
