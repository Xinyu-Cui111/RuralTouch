# 指尖善治 · 设计系统

> 与 `styles/theme.scss`、`docs/UI_UPGRADE_V2_LANDING.md` 同步。  
> 关键词：**简约 · 纸面 · 办事主线 · 适老化**

## 风格定位

轻量 · 温馨 · 村务 · 现代 — **少装饰、多留白、主任务清晰**

| 角色   | 色值      | 用途                 |
| ------ | --------- | -------------------- |
| 米纸底 | `#F6F0E4` | 页面背景             |
| 纸面白 | `#FFFCF7` | 卡片/输入面          |
| 朱砂红 | `#9E3428` | **主 CTA**、关键进度 |
| 麦金   | `#C9A24A` | **仅**荣誉 / 积分    |
| 橄榄   | `#5A6B38` | 议事 / 团购模块      |
| 藏青   | `#3A4A63` | 法治 / AI            |
| 正文   | `#2A2118` | 主文字               |
| 弱文案 | `#7A6B58` | 适老化加深           |

## 布局原则

1. **一屏一事** — 首屏按有/无待办切换主行动
2. **默认中性纸面卡** — 金 tone 只用于积分模块
3. **列表优先于堆卡**
4. **字阶** — Title≥36 / Body≥30 / Caption≥26
5. **触控** — 主按钮 min-height ≥ 88rpx
6. **Hero** — Tab 首页可氛围图；二级页用 `compact`

## 组件约定

| 组件        | 约定                       |
| ----------- | -------------------------- |
| `rt-card`   | 默认安静；装饰 opt-in      |
| `page-hero` | `compact` 无图无光球       |
| `rt-icon`   | CSS 字形；模块 tone 语义化 |
| 动效        | 禁止持续 3D / rotateY      |
