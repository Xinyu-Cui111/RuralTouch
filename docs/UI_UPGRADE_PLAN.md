# 全站 UI / 排版升级策划 · 指尖善治

> 角色：AI 产品经理视角的视觉与信息架构升级  
> 原则：**简约 · 人性化 · 悦目** — 不换品牌叙事，只减噪、加呼吸、统一节奏  
> 配色锁定：温馨乡土 × 党政感（米纸 / 朱砂 / 麦金 / 橄榄）— 见 `COLOR_ARCHIVE.md`  
> 主业务叙事不变：说事 → AI 成案 → 建档 → 干部推进

---

## 1. 诊断（现状问题）— 更正方向

| 要改                                                           | 不要改成                                       |
| -------------------------------------------------------------- | ---------------------------------------------- |
| **功能分区重复**（服务大厅 / 调解室 / AI 大卡 / FAB 多处入口） | 把金卡、渐变、光晕全拆成素白「简陋风」         |
| **同构四 Tab**（Hero→AI→ 金卡堆）                              | 取消乡土党政视觉识别                           |
| 信息扫描成本高                                                 | 去掉悦目细节；**也不要把合并后的页做空、干巴** |

**正确目标：** 分区合并、入口收敛；**视觉保持温润精致**（麦金纸面卡、主流程高光）；**合并区内信息仍饱满**（说明文案 / 要点 / 快捷入口，而不是只剩一个按钮）。

---

## 2. 设计原则（验收口令）

1. **一屏一事**：首屏只保留品牌/模块名 + 一个主行动 + 必要状态。
2. **纸面优先**：默认白/米纸面，无纹理；色条仅用于「法治 / 调解 / 荣誉」模块入口。
3. **字重阶梯**：显示 1 级标题 → 1 级正文 → 1 级辅助；禁止同卡内 4 种字号乱战。
4. **触控友好**：主按钮高 ≥ 88rpx；列表行高舒适；状态用色块字，不靠细线。
5. **卡片克制**：列表默认「分割线行」；卡片只包「可操作一组」或「AI 确认」等关键块。
6. **动效克制**：仅按压缩放 opacity、步骤条进度；禁止卡片 scale 闪动。

## 3. 视觉语言（简版 Spec）

| 层   | 规范                                                              |
| ---- | ----------------------------------------------------------------- |
| 背景 | `#F6F0E4` 米纸；分区用极浅橄榄/金软底，不用大图铺满内容区         |
| 主色 | 朱砂 `#9E3428` = 主 CTA / 关键进度                                |
| 点缀 | 麦金 = 积分荣誉；橄榄 = 议事；藏青 = 法治 AI                      |
| 圆角 | 内容块 `md`；按钮胶囊仅 CTA；Chip 用 `sm` 圆角矩形（少 999 全圆） |
| 阴影 | 默认无阴影或 `sm`；`elevated` 仅 Hero 下主操作块                  |
| 图标 | 继续 `rt-icon` CSS 字形；不用 emoji 当主图标                      |

## 4. 信息架构与分屏职责

| 页面      | 一屏一事     | 降噪动作                                      |
| --------- | ------------ | --------------------------------------------- |
| 登录      | 品牌 + 登录  | 减光球层数；协议行贴近按钮                    |
| 议事厅    | 提交纠纷     | 服务网格去金卡纹理；调解入口做真正主视觉      |
| 法治      | 普法入口     | 列表化要点，少重复金卡                        |
| 道德银行  | 积分数字     | 分数 Hero 简；列表用 cell                     |
| 团购      | 商品浏览     | 产品卡去装饰，图文清晰                        |
| 提交纠纷  | 说事 → 确认  | 步骤条置顶；确认页留白加大                    |
| 详情      | 进度+AI 摘要 | 合并多金卡为「进度 / 案情 / AI / 时间线」四段 |
| 助手/普法 | 对话         | 顶栏轻；气泡去多余边框                        |
| 我的      | 身份+入口    | Hero 减 orb；管理入口清晰                     |
| 工作台    | 待办推进     | 统计行 + 列表；按钮组二档（主/次）            |
| AI 质量   | 指标阅读     | 保持现有简约，统一字阶                        |

## 5. 分批落地（建议）

### Phase 0 · 系统地基 ✅

- 重写 `DESIGN_SYSTEM.md` 对齐 `theme.scss`
- `rt-card`：**默认关闭** stripe / pattern / glow 显眼层；`elevated` 才加强阴影
- 新增策划文档（本文）作验收标准

### Phase 1 · 主叙事三屏 ✅

登录 → 议事厅 → 提交纠纷（含确认）  
目标：面试录屏第一眼「干净、敢点、看得懂」

### Phase 2 · 闭环与 Tab ✅（本轮）

详情 · 记录 · 工作台 · 助手/普法 · 法治/道德/团购/我的  
目标：去掉默认金卡厚装饰，纸面列表为主

### Phase 3 · Tab 差异化（可选下一轮）

法治藏青点缀 / 道德积分强调 / 团购产品图为主 — 在安静底上做模块色差

### Phase 4 · 打磨

空状态、表单、onboarding；截图进 `screenshots/`

## 6. 组件级改造清单

| 组件        | 现状          | 目标                                     |
| ----------- | ------------- | ---------------------------------------- |
| `rt-card`   | 默认全装饰    | 默认安静纸面；`tone` 仅淡底；装饰 opt-in |
| `page-hero` | 大图+mesh+orb | 保留一张氛围图；减弱 orb；标题更大更少字 |
| `ai-entry`  | 厚照片块      | 改为细长入口条或轻卡，不抢「提交纠纷」   |
| `tab-bar`   | 悬浮玻璃      | 略降高度/阴影，选中态用朱砂点而非大块金  |
| `ai-fab`    | 常驻          | 主链路页可收；或仅非对话页显示           |
| Chip/Pill   | 复制粘贴      | 抽 `rt-chip`（后续 Phase 2）             |

## 7. 成功标准（可测）

- [ ] 议事厅首屏：一眼能指出「提交纠纷」为主按钮
- [ ] 任意列表页：单屏可见信息密度下降，滚动更顺
- [ ] 录屏截图：去掉装饰后仍能认出「指尖善治」品牌色
- [ ] 中老年可读：正文 ≥ 28rpx，辅助 ≥ 24rpx
- [ ] 性能：不新增大图；继续禁重 SVG
