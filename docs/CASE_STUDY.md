# 案例复盘 · AI 辅助基层纠纷建档

> 作品：指尖善治（RuralTouch）  
> 角色：独立 AI 产品负责人（规划 / 交互 / 实现 / 评测）  
> 用途：面试 3–5 分钟主讲述 + 深挖底稿

---

## 1. 一句话

在基层调解场景里，用 **「说事 → AI 整理确认 → 建档 → 干部推进」** 替代「空白表单硬填 + 纯聊天机器人」，让村民敢提交、干部看得懂、高风险能转人工。

---

## 2. 用户与痛点

| 角色   | 痛点                       | 产品回应                                               |
| ------ | -------------------------- | ------------------------------------------------------ |
| 村民   | 不会写「案由」，口语冗长   | 场景 Chip + AI 生成标题/摘要/步骤                      |
| 调解员 | 建档慢、分类乱、风险看不见 | `aiMeta` 入库：类型/风险/依据/周期                     |
| 试点方 | 怕幻觉、怕责任             | 规则降级、法律名称级引用、高风险升级提示、普法免责声明 |

---

## 3. 方案取舍（面试高分点）

| 方案                 | 为何不选 / 为何选                                    |
| -------------------- | ---------------------------------------------------- |
| 纯 LLM Chat          | 无结构化建档，干部无法推进流程                       |
| 纯表单               | 中老年填写负担高，完成率低                           |
| **LLM + 规则双引擎** | 有 Key 用 LLM；无 Key / 失败自动规则，演示与上线都稳 |
| 大而全「村务 GPT」   | 同质化；改为 **一条调解主链路做透**                  |

技术形态（产品视角）：

```
输入口述 →（可选 LLM JSON）→ 规则兜底
  → 展示：摘要 / 风险 / 法律依据 / 建议步骤
  → 高风险：升级横幅（转村委/报警路径）
  → 确认提交 → rt_disputes.aiMeta
  → 管理端一键受理/办理/办结
```

| 指标       | 怎么量                                    | 当前基线（产品设计）                 |

| AI 事件    | `rt_ai_events`                            | action / source / latency / escalate |

## 5. 演示脚本（4 分钟）

1. **议事厅**（15s）：定位「村民议事 / 调解」
2. **提交纠纷**（90s）：选 Chip「土地边界」→ 口述补充 →「整理成案」
3. **确认页**（60s）：指给面试官看风险标签、法律依据、建议步骤、来源；若演示高风险文案则指升级条
4. **建档成功**（30s）：进度条四步；可点「咨询此案」
5. **管理端**（45s）：一键受理 → 办理 → 办结（+ 积分激励）；可带一眼 AI 质量
6. **收尾**（20s）：「评测集每周抽检 + Badcase 改规则/prompt」

## 6. 深挖问答（预备）

**Q: 幻觉怎么控？**  
A: 建档输出强制结构化字段；法律只引用「法律名称」不编造条款号；LLM 失败走规则；普法页固定免责声明；高风险不给「自行了断」建议，引导村委/报警。

**Q: RAG 怎么做的？算不算「真 RAG」？**  
A: 场景知识表 `faq.json` + 关键词 TopK 检索（`knowledge.js`），命中条目拼进 Prompt 或无 Key 时直接 FAQ 回答；UI 展示「参考」chips 与 `source`（`rag` / `rag_llm` / `rule` / `llm` / `cache`）。不是向量库，但是可解释、可演示的检索增强。

**Q: 和 ChatGPT 套壳差在哪？**  
A: 差在 **业务对象是纠纷档案与阶段状态机**，AI 是建档与分流的一环，不是会话本身。

**Q: 数据从哪来？**  
A: 种子评测集（匿名合成案情）+ 真实演示反馈；不上线真实身份数据到作品集材料。

**Q: 无 API Key 还能演示吗？**  
A: 能。无 Key → 规则/`rag` FAQ；有 Key → LLM 或 `rag_llm`；超时/失败 → `rule_fallback`；同案情 5 分钟内重复整理 → `cache`。确认页会标出来源。

**Q: 谁付费？合规红线？**  
A: 见 [COMPLIANCE.md](COMPLIANCE.md)——项目制付费假设；不替代法律意见；高风险转人工；数据在微信云。
