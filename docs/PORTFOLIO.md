## 一句话定位

基层调解垂直 AI：**说事 → AI 整理成案 → 确认建档 → 干部推进 → 评测/Badcase**，不是泛 Chat 套壳。

## 作品页建议结构（1 屏）

1. 标题 + 一句话
2. 4–6 分钟 Demo 链接（见下）
3. 3 张主图：确认页（依据/风险）· 升级条 · 管理端 / AI 质量
4. 指标：评测 10/10 基线；规则降级可用；RAG FAQ 可引用
5. 链接：本仓库 README · [CASE_STUDY](CASE_STUDY.md) · [COMPLIANCE](COMPLIANCE.md)
