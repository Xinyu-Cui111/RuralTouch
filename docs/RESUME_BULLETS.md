## 项目一行

**指尖善治（RuralTouch）**｜智慧村务微信小程序｜独立 AI 产品负责人（规划 / 交互 / 云开发实现 / 评测）

## 三条成就（推荐）

1. 设计并落地基层调解垂直 AI 主链路「说事 → AI 整理成案 → 建档 → 干部推进」，以纠纷档案与阶段状态机为业务对象，区别于泛 Chat 套壳。
2. 搭建规则 + LLM + FAQ 检索双/三引擎：无 Key 可降级演示；确认页展示来源（大模型/规则/检索/短缓存）；高风险升级与诉讼输赢拒答产品化。
3. 建立评测与闭环：`dispute-cases` 金标（分类/风险/升级 10/10 基线）、`rt_ai_events` 与 AI 质量看板、Badcase 标注与标题采纳 `titleEdited` 埋点。

## 可选补充一句
